# Exercício 1 — Controle de velocidade de motor DC

Predictive fuzzy logic controller (Mamdani approach) for a DC motor.

## Specification

- Motor speed: ω ∈ [0, 1000] rpm
- Power supply voltage: V ∈ [0, 100] V
- Maximum (de)acceleration: ±1 rpm/s
- Voltage actuation rate: ±1 V/s

Inputs to the FIS: `velocidade`, `alimentacao`. Output: `aceleracao` ∈ [-1, +1] **V/s** — a
voltage rate, not a speed rate. The plant's own dynamics (`omega_ss = 10 * V`, then a ±1
rpm/s rate limiter) turn a change in `V` into a change in `omega`; see REPORT.md §2 for the
gap this opens between the commanded and actual rates.

## Files

- `motor_control.py` — full solution: Mamdani FIS, block-diagram plant model, closed-loop
  simulation, plots.
- `REPORT.md` — full writeup (math, rule base, results, conclusions).
- `diagram.json` — the block diagram as a spec file, generated by `motor_control.py`.
- `figures/` — generated PNGs.

## Running

Install the package once from the repository root, then run the script:

```bash
pip install -e .
python exercises/exercicio1_motor_control/motor_control.py
```

Generates five figures in `figures/` plus `diagram.json`, and prints the pointwise
evaluation table and closed-loop summary statistics.
