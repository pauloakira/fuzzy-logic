# Exercício 2 — Controle ativo de vibrações em estrutura SDOF

Mamdani fuzzy controller for active vibration suppression of a single-degree-of-freedom (SDOF) mass-spring-damper structure under harmonic excitation.

## Specification

- Plant: SDOF mass-spring-damper, $m\ddot{x} + c\dot{x} + kx = F_\text{ext}(t) + u(t)$
- $m = 1$ kg, $k = 100$ N/m, damping ratio $\zeta = 0.02$ → natural frequency $\omega_n = 10$ rad/s
- Excitation: harmonic, $F_\text{ext}(t) = F_0 \sin(\omega t)$ with $F_0 = 1$ N
- Control: active force $u(t) \in [-3, +3]$ N from a Mamdani FIS

Inputs to the FIS: `deslocamento` ∈ [-0.3, +0.3] m, `velocidade` ∈ [-3, +3] m/s. Output: `forca` ∈ [-3, +3] N. Five linguistic terms each (NG, NP, Z, PP, PG); 5 × 5 phase-plane rule base.

## Files

- `sdof_vibration.py` — full solution: Mamdani FIS, block-diagram simulation, plots.
- `pid_comparison.py` — follow-up study: classical PID on the same plant, plus a sweep of the fuzzy controller's input scaling gain.
- `REPORT.md` — full writeup. The four required deliverables (input variables, output variables, rules, application example) are each their own labeled section.
- `REPORT_comparison.md` — the PID comparison writeup.
- `diagram.json` — the block diagram as a spec file, generated by `sdof_vibration.py`.
- `figures/` — generated PNGs.

## Running

Install the package once from the repository root, then run either script:

```bash
pip install -e .
python exercises/exercicio2_sdof_vibration_control/sdof_vibration.py   # ~35 s
python exercises/exercicio2_sdof_vibration_control/pid_comparison.py   # ~55 s
```

The first generates seven figures plus `diagram.json` and prints controlled vs. uncontrolled metrics; the second generates four more and prints the fuzzy/PID comparison and the scaling-gain sweep.

Both take tens of seconds because the simulation horizon is 40 s. That is deliberate: the plant is lightly damped ($\tau = 1/(\zeta\omega_n) = 5$ s), so a shorter run does not reach steady state, and an earlier 12 s horizon measured the *uncontrolled* reference 9 % below its true amplitude while the controlled cases had already settled.
